# Angebots-Teil für Bauunternehmen – Checkliste + Quellen

Stand: 2026-09-27 | Zielgruppe: Bauunternehmen (privat/gewerblich + öffentlich VOB)
Geltung: Nur Angebots-Erstellung + Abgabe. Auftrag/Ausführung/Abrechnung sind Folge-Module.

## 1. Abgabe-Paket (vom Auftraggeber verlangt – Pflicht)

### 1.1 Angebotsschreiben VHB 213
- [ ] Bietername, Anschrift, USt-ID, HR-Nr., Kontakt
- [ ] Vergabenummer, Baumaßnahme, Leistung
- [ ] Angebotsendsumme Hauptangebot inkl. USt
- [ ] Bindefrist-Bindung (Regel ~60 Kalendertage, Enddatum als Kalendertag)
- [ ] Preisnachlass % ohne Bedingung an bezeichneter Stelle
- [ ] Anzahl Nebenangebote
- [ ] Anerkennung VOB/B + Langfassung LV als alleinverbindlich
- [ ] Präqualifikation PQ-Nummer oder 124 beigefügt
- [ ] Unterschrift / qualifizierte Signatur bei e-Vergabe

### 1.2 Leistungsverzeichnis verpreist + GAEB
- [ ] LV-Struktur: Los / Titel / OZ, nur gleichartige Leistungen je OZ
- [ ] Kurz-/Langtext Trennung, STLB-Bezug wo gefordert
- [ ] EP je Position ohne USt, max. 3 Nachkommastellen
- [ ] X83 Import -> EP eintragen -> X84 Export, summenidentisch mit PDF
- [ ] Keine Änderung an Text/Menge, nur Preise + zugelassene Bieterangaben
- [ ] Lose vollständig, auch als eine GAEB-Datei bei Losvergabe

### 1.3 EFB + Urkalkulation
- [ ] 221 bei Zuschlagskalkulation ODER 222 bei Endsumme
- [ ] 223 Aufgliederung der Einheitspreise
- [ ] Verrechnungslohn ML/KL/VL, BGK/AGK/WuG/Gewinn schlüssig
- [ ] Urkalkulation auf Verlangen, auch für Nachunternehmer
- [ ] Kein Mischkalkulations-Umlagern (Ausschlussgrund)
- [ ] Verprobung 221 vs 223, Angebotssumme = EFB-Summe

### 1.4 Bieterangaben / Produkte
- [ ] Hersteller + Typ bei „oder gleichwertig“, sonst gilt AG-Produkt
- [ ] Bietertextergänzungen nur wo zugelassen
- [ ] Gleichwertigkeitsnachweis auf Verlangen

### 1.5 Eignung 124 / PQ / EEE
- [ ] 124 Eigenerklärung: Umsatz 3 Jahre, Referenzen 5 Jahre mit AG-Bestätigung
- [ ] Arbeitskräfte-Verfügbarkeit, BG-Mitgliedschaft
- [ ] Keine Insolvenz/Liquidation, keine falschen Erklärungen
- [ ] PQ-Nummer oder EEE bei EU-Verfahren

### 1.6 Nachunternehmer / ARGE / Eignungsleihe
- [ ] 233 Verzeichnis NU-Leistungen
- [ ] 234 Bietergemeinschaft gesamtschuldnerisch + Bevollmächtigter
- [ ] 235 Verzeichnis Kapazitäten anderer Unternehmen
- [ ] 236 Verpflichtungserklärung NU + 124 vom NU

### 1.7 Sicherheiten / Termine / Klauseln
- [ ] Sicherheiten nach 214: Vertragserfüllung ~5%, Gewährleistung, Vorauszahlung
- [ ] Ausführungsfristen Beginn/Ende, Bauzeitenplan wo gefordert
- [ ] Vertragsstrafe-Regelung anerkannt
- [ ] 224 Lohngleitklausel wo gefordert
- [ ] Tariftreue/Mindestentgelt-Erklärung, Holz 248 wo gefordert

### 1.8 Nebenangebote
- [ ] Nur wenn zugelassen (Hauptangebot + Mindestanforderungen)
- [ ] Auf gesonderter Anlage, deutlich gekennzeichnet
- [ ] Anzahl im 213 eingetragen

### 1.9 Formal-Check vor Abgabe (Preflight)
- [ ] Fristgerecht elektronisch eingegangen (Sekunden zählen)
- [ ] Signiert/unterschrieben, vertraulich übermittelt, Datenintegrität
- [ ] Vollständig: Preise + alle geforderten Angaben/Erklärungen
- [ ] Keine Änderungen an Vergabeunterlagen
- [ ] Preisprüfung bestehen: keine >10% Abweichung ohne Aufklärung, kein unangemessen niedrig ohne Nachweis
- [ ] Sprache Deutsch, Währung Euro

## 2. Intern (verlangt AG nicht, braucht Bauunternehmer)
- [ ] EKT-Kalkulation, DB I/II, Mittellohn-Profil
- [ ] Versionierung A/B/C, Vergleich N vs N-1
- [ ] Preisspiegel, Alternativ/Wahl/Bedarf intern rechnen
- [ ] Nachfass-Datum, Bindefrist-Ampel
- [ ] GAEB-Preflight: OZ lückenlos, EFB dabei, Summe PDF=X84

## 3. Abgrenzung (nicht Angebot)
Auftrag X86, Bauausführung, Bautagebuch, Aufmaß DA11/X31, Abschlag/Schluss X89/XRechnung, Nachtrag VOB §2, Abnahme, Mängel, Bürgschaftsverwaltung.

Zusätzlich würde ich starre technische Vorgaben wie „maximal drei Nachkommastellen“, „alle Lose in einer GAEB-Datei“ und „PDF muss immer mit X84 übereinstimmen“ nicht ohne Prüfung als allgemeingültige Regeln programmieren. Hinterlege stattdessen die Vorgaben des jeweiligen Auftraggebers beziehungsweise Dateiformats und prüfe Summen dort, wo tatsächlich beide Ausgabeformen verlangt werden. Diese Formulierungen stehen derzeit zu absolut in der Checkliste.
Vorschlag für die neue Struktur

    Kundenangebot: Kunde, Bauvorhaben, Leistungspositionen, Mengen, Einheitspreise, Steuer, Ausführungstermin, Angebotsgültigkeit, PDF und interne Freigabe.

    Öffentliche Ausschreibung: Vergabenummer, Fristen, Lose, übernommenes Leistungsverzeichnis, geforderte Formblätter, Nachweise und zulässiger Abgabeweg.

    Interne Kalkulation: Lohn, Material, Geräte, Nachunternehmer, Zuschläge, Marge und Angebotsversionen – getrennt von den Unterlagen, die der Auftraggeber erhält.

    Abgabeprüfung: Nur für das betreffende Verfahren relevante Prüfungen, etwa fehlende Preise, geforderte Anhänge, Frist, Dateiformat und Übermittlungsform.

Die bestehende Abgrenzung zu Auftrag, Bauausführung und Rechnung würde ich beibehalten. Sie hilft, das Angebotsmodul nicht mit späteren Projektphasen zu überladen.

Priorität für die Bearbeitung: zuerst die falschen pauschalen Pflichten und Fristen korrigieren, danach die Checkliste in „Kundenangebot“ und „Ausschreibung“ aufteilen. Erst auf dieser Grundlage würde ich Formblatt- und GAEB-Funktionen in W‑Link spezifizieren.
